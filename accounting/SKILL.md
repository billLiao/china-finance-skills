# 中国会计准则 · 记账理账

基于《小企业会计准则》(财会[2011]17号) 与《企业会计准则》(财会[2006]3号及后续修订) 构建的记账理账技能，覆盖小企业（年收入<500万）→ 成长企业（500-3000万）→ 中型企业（3000万+）全规模段。

## 工作流总览

```
准则选择（必读）→ 建账（科目表）→ 日常记账（凭证）→ 月末结账 → 编制报表 → 税务处理
```

## 第一步：准则选择（记账前必读）

中国目前有两套并行会计准则体系，**选错准则 = 从科目到报表全盘错误**。

### 判断决策树

```
企业是否属于以下任一情形？
├── 股票或债券在公开市场交易
├── 金融机构或具有金融性质的企业
├── 企业集团内的母公司或子公司
└── 年应征增值税销售额 > 500万元（一般纳税人）
       │
       ├── 是 → 【企业会计准则】
       │
       └── 否 → 是否符合小企业划型标准？
               │
               ├── 是 → 【小企业会计准则】或自愿选择【企业会计准则】
               └── 否 → 【企业会计准则】
```

### 典型适用场景

| 场景 | 推荐准则 | 原因 |
|------|---------|------|
| 年收入 < 500万的小微企业 | 小企业会计准则 | 科目简单、不计提减值、无递延税 |
| 年收入 500万-3000万的成长企业 | **企业会计准则** | 已有一定规模，税务上通常是一般纳税人 |
| 年收入 > 3000万 | **企业会计准则** | 规模以上企业 |
| 有外部融资需求（银行贷款/股权融资） | **企业会计准则** | 银行和投资人通常要求企业准则报表 |
| 有多家子公司或关联公司 | **企业会计准则** | 涉及合并报表 |
| 未来计划上市 | **企业会计准则** | 上市必须用企业准则 |
| 个体工商户/个人独资企业 | 小企业会计准则 | 税务上按经营所得缴个税 |

### 两套准则核心差异速查

| 维度 | 小企业会计准则 | 企业会计准则 |
|------|--------------|-------------|
| **科目数量** | ~66 | ~167 |
| **资产减值** | 不计提 | 计提（坏账/存货跌价/固定资产减值等） |
| **坏账处理** | 直接转销→营业外支出 | 备抵法→信用减值损失 |
| **金融资产** | 成本模式 | 三类（摊余成本/FVOCI/FVTPL） |
| **所得税** | 应付税款法 | **资产负债表债务法**（递延所得税） |
| **以前年度差错** | 未来适用法 | 追溯调整法 |
| **融资租赁** | 付款总额入账 | 使用权资产+租赁负债 |
| **财务报表** | 三表一注 | 四表一注（含所有者权益变动表） |

### 转换规则

- 已执行企业会计准则的企业 → **不能转回**小企业会计准则
- 现在用小企业准则的企业 → 可以**自愿升级**为企业会计准则

### 判断输出

判断完成后，先向用户输出结论再继续后续步骤：

```
📋 会计准则选择判断
════════════════════════════════════
企业基本信息：
  年收入规模 / 从业人数 / 资产总额
  增值税纳税人类型：□ 小规模纳税人 □ 一般纳税人
  是否涉及公开市场 / 是否有外部融资需求
────────────────────────────────────
判断结论：适用【企业会计准则】
理由：年收入超过500万元/为一般纳税人/有外部融资需求
后续所有记账理账请使用【企业会计准则】版本。
════════════════════════════════════
```

> 如果不确定，默认选择**企业会计准则**——宁可科目复杂一些，也好过将来升级准则时重新做账。

## 使用原则

1. **先判断准则，再动手做账**——所有参考文档内部均区分小企业版/企业准则版
2. **按需加载**——只读当前任务需要的参考文档，凭证编制时不必加载报表文档
3. **数字可追溯**——报表数据应能追溯到科目余额和记账凭证
4. 涉及跨准则科目（如递延税、使用权资产）时，先查 `references/coa-mapping.md` 确认小企业准则下的替代处理
