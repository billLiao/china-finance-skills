
# 标准会计科目表

## 使用前必读

根据企业实际情况选择对应版本：

> **快速判断**：一般纳税人 / 年收入≥500万 / 有融资需求 / 多子公司 / 计划上市 → **企业准则版**（167科目）。不涉及以上任一情形的小微企业 → **小企业版**（66科目）。不确定时默认选企业准则版。已选企业准则后不可转回小企业准则。

- **小企业会计准则**（年收入<500万、不涉及公开交易、非金融机构）→ 使用下方"小企业版"
- **企业会计准则**（一般纳税人、千万级收入、有融资需求、多子公司）→ 使用下方"企业准则版"
- 准则判断决策树见本技能 SKILL.md「准则选择」一节

## 小企业 vs 企业准则 — 科目差异速查

| 关键差 | 小企业无此科目 | 企业准则有 |
|--------|--------------|-----------|
| 减值的备抵科目 | 无任何减值准备科目 | 坏账准备、存货跌价准备、固定资产减值准备、无形资产减值准备、商誉减值准备等 |
| 金融资产 | 短期投资 / 长期债券投资 | 交易性金融资产 / 债权投资 / 其他债权投资 / 其他权益工具投资 |
| 长期股权投资 | 统一成本法 | 成本法或**权益法**（对合营/联营企业） |
| 投资性房地产 | 无独立科目 | 单独科目，可选公允价值模式 |
| 递延所得税 | 无 | 递延所得税资产 / 递延所得税负债 |
| 商誉 | 无 | 商誉 / 商誉减值准备 |
| 公允价值计量 | 无 | 公允价值变动损益、交易性金融资产/负债 |
| 资产处置 | 通过营业外收支 | 通过"资产处置损益"单独列示 |
| 政府补助 | 全部→营业外收入 | 日常相关→其他收益，非日常→营业外收入 |
| 以前年度差错 | 未来适用法 | **追溯调整法**（通过"以前年度损益调整"） |
| 新收入准则科目 | 预收账款 | 合同资产 / 合同负债 |
| 租赁 | 付款总额入账 | 使用权资产 + 租赁负债 |
| 合并报表 | 不编制 | 母公司编制合并报表 |
| 所有者权益变动表 | 不编 | 必须编制 |

## 使用方式

1. 先用 SKILL.md「准则选择」确定企业适用准则
2. 从本表中找到对应版本的科目
3. 使用 `journal-entry` 技能编制凭证时确保科目编号和名称正确
4. 使用 `profit-loss` / `balance-sheet` 时采用对应版本格式

> 完整科目表依据：财会[2011]17号《小企业会计准则》及财会[2006]3号《企业会计准则——应用指南》附件科目表，结合新准则修订更新。
