
# 个人所得税

## 概述
中国的个人所得税分为**综合所得**（工资薪金/劳务报酬等）和**经营所得**（个体工商户/个人独资企业等）两大类。小企业常见的场景包括：给自己发工资、给员工发工资、个体工商户经营所得申报。

## 一、综合所得（工资/劳务报酬）

### 税率表（七级累进）

| 级数 | 全年应纳税所得额 | 税率 | 速算扣除数 |
|------|-----------------|------|-----------|
| 1 | ≤ 36,000 | **3%** | 0 |
| 2 | 36,000 ~ 144,000 | **10%** | 2,520 |
| 3 | 144,000 ~ 300,000 | **20%** | 16,920 |
| 4 | 300,000 ~ 420,000 | **25%** | 31,920 |
| 5 | 420,000 ~ 660,000 | **30%** | 52,920 |
| 6 | 660,000 ~ 960,000 | **35%** | 85,920 |
| 7 | > 960,000 | **45%** | 181,920 |

### 计算公式

```
应纳税所得额 = 累计收入 - 累计减除费用(5000/月) - 累计专项扣除 - 累计专项附加扣除
应纳税额 = 应纳税所得额 × 税率 - 速算扣除数 - 累计已缴税额
```

### 专项附加扣除（2025年标准）

| 扣除项目 | 标准 | 说明 |
|----------|------|------|
| 子女教育 | 2,000元/月/子女 | 3岁到博士 |
| 继续教育 | 400元/月 | 学历教育期间 |
| 大病医疗 | 年度限额80,000元 | 医保目录内自付部分 |
| 住房贷款利息 | 1,000元/月 | 首套房，最长240个月 |
| 住房租金 | 800/1,100/1,500元/月 | 按城市级别 |
| 赡养老人 | 3,000元/月 | 年满60岁父母 |
| 婴幼儿照护 | 2,000元/月/子女 | 3岁以下 |

### 社保公积金（以北京为例）

| 项目 | 单位比例 | 个人比例 |
|------|---------|---------|
| 养老保险 | 16% | 8% |
| 医疗保险 | 9%+3元 | 2%+3元 |
| 失业保险 | 0.5% | 0.5% |
| 工伤保险 | 0.2%-1.9% | — |
| 生育保险 | 已并入医保 | — |
| 住房公积金 | 5%-12% | 5%-12% |

### 工资计算完整示例

```
📋 工资个税计算 — 2026年5月
════════════════════════════════════

基本信息：
  月薪：                    20,000.00
  社保基数：                20,000.00
  公积金比例：                   12%

扣除项：
  社保个人缴纳：             2,100.00
    养老(8%) 1,600 + 医疗(2%) 400 + 失业(0.5%) 100
  公积金个人缴纳：           2,400.00  (12%)
  专项附加扣除：             3,000.00
    子女教育 2,000 + 赡养老人 1,000(兄弟分摊)
  基本减除费用：             5,000.00
  扣除合计：                12,500.00

────────────────────────────────────
应纳税所得额：               7,500.00
  = 20,000 - 12,500

累计应纳税所得额（1-5月）：  37,500.00
适用税率：                       10%
累计应纳税额：               1,230.00
  = 37,500 × 10% - 2,520

累计已预缴（1-4月）：          984.00
本月应扣缴：                   246.00
────────────────────────────────────

实发工资：                 15,254.00
  = 20,000 - 2,100 - 2,400 - 246
════════════════════════════════════
```

## 二、经营所得（个体工商户/个人独资企业）

### 税率表（五级累进）

| 级数 | 全年应纳税所得额 | 税率 | 速算扣除数 |
|------|-----------------|------|-----------|
| 1 | ≤ 30,000 | **5%** | 0 |
| 2 | 30,000 ~ 90,000 | **10%** | 1,500 |
| 3 | 90,000 ~ 300,000 | **20%** | 10,500 |
| 4 | 300,000 ~ 500,000 | **30%** | 40,500 |
| 5 | > 500,000 | **35%** | 65,500 |

### 优惠政策（至2027年12月31日）

> 年应纳税所得额 ≤ **200万元**的部分 → **减半征收**个人所得税
> 
> 来源：财政部税务总局公告2023年第12号
> 不区分查账/核定征收方式

### 计算示例

```
📋 个体工商户经营所得个税计算 — 2026年度
════════════════════════════════════

全年收入总额：              800,000.00
减：成本费用：              500,000.00
减：基本减除费用：           60,000.00  (5000/月×12)
────────────────────────────────────
应纳税所得额：              240,000.00

适用税率：                       20%   (第3级)
应纳税额：                   37,500.00
  = 240,000 × 20% - 10,500

减半优惠(≤200万部分)：      20,000.00
  = (200,000 × 20% - 10,500) × 50%
  + (40,000 × 20%)          ← 超出200万部分

实际应缴税额：               29,500.00
实际税负率：                    3.69%  (= 29,500/800,000)
════════════════════════════════════
```

### 申报时间

| 项目 | 时间 |
|------|------|
| 季度预缴 | 季度终了后15日内 |
| 年度汇算清缴 | 次年1月1日至3月31日 |

## 工资发放分录模板

**计提工资**：
```
借：管理费用 — 工资               20,000.00
  贷：应付职工薪酬 — 工资          20,000.00
```

**计提社保（单位部分）**：
```
借：管理费用 — 社保                5,300.00  (≈20,000×26.5%)
  贷：应付职工薪酬 — 社保           5,300.00
```

**发放工资**：
```
借：应付职工薪酬 — 工资            20,000.00
  贷：银行存款                      15,254.00
      其他应付款 — 社保(个人)        2,100.00
      其他应付款 — 公积金(个人)      2,400.00
      应交税费 — 应交个人所得税        246.00
```

**缴纳社保公积金**：
```
借：应付职工薪酬 — 社保             5,300.00
    其他应付款 — 社保(个人)          2,100.00
    其他应付款 — 公积金(个人)        2,400.00
  贷：银行存款                       9,800.00
```

## 重要提示

- 年终奖可选择**单独计税**（不并入综合所得），优惠至2027年12月31日
- 个人所得税是**代扣代缴**制，企业有义务在发薪时代扣
- 逾期未申报或未代扣的，税务机关将处以罚款
- 个体工商户经营所得和综合所得**分别计算**，各自享受扣除
