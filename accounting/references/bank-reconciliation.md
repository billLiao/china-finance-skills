
# 银行对账与余额调节

## 概述
这是一个**日常核对型**技能：把银行对账单和银行存款日记账逐笔核对，找出未达账项，编制余额调节表。与 `audit/cash.md` 的区别——那个是审计视角（函证、截止测试），这个是每月必做的日常动作。账实不符的银行存款，报表就是错的。

## 对账流程（每月一次，次月初）

```
1. 取数：网银下载当月对账单（PDF/Excel）
2. 核对：与银行存款日记账逐笔勾对（金额+日期+收付方向）
3. 标记：双方都有 → 勾掉；单边有 → 未达账项
4. 调节：编制银行存款余额调节表
5. 追踪：未达账项下月必须清掉，长期未达要查原因
```

## 四类未达账项

| 类型 | 例子 | 对余额的影响 |
|------|------|------------|
| ① 企业已收、银行未收 | 收到支票已入账，银行尚未清算 | 企业账 > 银行账 |
| ② 企业已付、银行未付 | 已开出的支票对方未兑付 | 企业账 < 银行账 |
| ③ 银行已收、企业未收 | 客户直接打款、银行利息入账 | 银行账 > 企业账 |
| ④ 银行已付、企业未付 | 银行扣手续费、贷款自动扣息 | 银行账 < 企业账 |

## 余额调节表

```
调节公式：
企业日记账余额 + ③银行已收企业未收 − ④银行已付企业未付
   = 银行对账单余额 + ①企业已收银行未收 − ②企业已付银行未付
```

## 调节不平的排查顺序

1. **核对方向**：收付方向记反（银行账以"企业视角"记，对账单是"银行视角"，方向天然相反）
2. **金额尾差**：手续费、利息这类零星金额最容易漏
3. **一拆多/多合一**：企业一笔 10 万，银行分两笔 6 万+4 万入账——按金额硬匹配会失败，按日期段+合计匹配
4. **跨期在途**：月末最后一天的交易，银行次日才记账——先确认是不是单纯的时间差
5. **重复记账/漏记**：调节仍不平，按日切分核对，锁定差异日再逐笔
6. **异常情形**：银行账上多出/少了说不清的钱——立即联系银行查流水明细，警惕盗刷、误入账、冻结扣划

## 支付宝 / 微信支付对账

| 事项 | 处理 |
|------|------|
| 科目 | 支付宝/微信余额挂「其他货币资金——支付宝/微信」，不是银行存款 |
| 对账单 | 平台后台导出流水账单，与该科目日记账核对，方法同上 |
| 提现在途 | 已申请提现未到账 = 企业已减其他货币资金、银行未收——典型未达账 |
| 余额宝/零钱理财 | 单独明细核算，编制现金流量表时注意其赎回不属于"现金等价物"随意调整 |
| 平台手续费 | 按账单逐笔或按月汇总计入财务费用，别漏 |

## 重要提示

- **调节表不调账**：未达账项不做任何分录，等凭证到达（银行回单、利息单）才入账；调节表只是核对工具
- 未达账项**下月必须清**：连续两个月同一笔未达，大概率是错账、漏记或票据问题，逐笔查
- 银行手续费、利息这些**银行单边记账**项目，取得回单后当月入账，别拖成习惯性未达
- 多账户企业每个账户单独一张调节表，别混调；定期账户也要对（利息计提是否与银行一致）
- 网银 U 盾、制单与复核权限分离是内控底线：出纳不能既付款又独自对账——对账最好由会计做，出纳回避
- 对账单是外部证据：审计函证之外，每月装订对账单+调节表是最基本的自查留痕
