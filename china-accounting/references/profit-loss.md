
# 利润表生成

## 使用前必读

根据企业实际情况选择对应版本：

> **快速判断**：一般纳税人 / 年收入≥500万 / 有融资需求 / 多子公司 / 计划上市 → **企业准则版**（完整利润表，含减值/公允价值变动/递延税）。不涉及以上任一情形的小微企业 → **小企业版**（简化利润表）。不确定时默认选企业准则版。准则判断决策树见本技能 SKILL.md「准则选择」一节。

- 小企业准则 → 版本一
- 企业准则 → 版本二（千万级企业必用）

## 关键新增项目说明

| 新增项目 | 核算内容 | 示例 |
|---------|---------|------|
| **其他收益** | 与企业日常活动相关的政府补助 | 稳岗补贴、即征即退增值税 |
| **公允价值变动收益** | 交易性金融资产/负债公允价值变动 | 持有的股票市价波动 |
| **信用减值损失** | 以预期信用损失模型计提的坏账 | 应收账款计提5%坏账 |
| **资产减值损失** | 固定资产、无形资产、商誉等的减值 | 机器设备因技术淘汰减值 |
| **资产处置收益** | 出售固定资产、无形资产的净收益/损失 | 卖掉旧车溢价3万 |
| **研发费用** | 从管理费用中单独列示 | 研发人员薪酬+材料 |
| **利息费用/利息收入** | 财务费用中的利息明细单独列示 | 银行借款利息 |
| **其他综合收益** | 未进利润表的利得和损失 | 其他债权投资公允价值变动 |
| **综合收益总额** | =净利润 + 其他综合收益 | 全面反映股东财富变化 |

> 千万级企业的利润表结构远比小企业复杂——这反映了会计准则对透明度的高要求。

# 两版通用的分析输出

无论用哪个版本，分析输出格式相同：

## 关键指标

### 毛利率
```
毛利率 = (营业收入 - 营业成本) / 营业收入 × 100%
```

### 息税前利润（EBIT）
```
EBIT = 利润总额 + 利息费用
→ 剔除资本结构和税率影响的经营盈利能力（千万级企业融资方关心的核心指标）
```

### EBITDA
```
EBITDA = EBIT + 本期折旧 + 本期摊销
→ 更接近经营性现金流的指标
```

### 净利率
```
净利率 = 净利润 / 营业收入 × 100%
```

## 利润质量分析（千万级企业必做）

| 分析角度 | 方法 | 预警信号 |
|---------|------|---------|
| 现金流支撑度 | 经营现金流/净利润 | 持续<0.7 → 利润"虚胖"，应收账款堆积 |
| 非经常性损益占比 | 非经常性损益/净利润 | >30% → 真实盈利能力被高估 |
| 毛利率稳定性 | 连续6季度跟踪 | 持续下降 → 竞争恶化或成本失控 |
| 研发/销售投入 | 与同行比较 | 显著低于同行 → 可能靠压缩长期投入维持短期利润 |

## 重要提示

- 企业准则下的利润表**不能跨年比较口径不一致的数据**（某年用新准则某年用旧准则）
- 其他综合收益不进入净利润，但进入综合收益总额 → 看报表要看全
- 千万级企业如果毛利率很低但净利率正常 → 费用控制强，但可能牺牲了长期竞争力（如减少研发投入）
- 银行和投资机构看的企业版利润表，信用减值损失和资产减值损失是重点（反映资产质量）
