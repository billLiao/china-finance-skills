
# 现金流量表生成

## 概述
生成符合《小企业会计准则》的现金流量表。现金流量表反映企业在一定期间内现金和现金等价物的流入和流出，帮助判断企业的支付能力和资金周转情况。

## 生成流程

1. **确认报告期间**：通常是月份、季度或年度
2. **获取期初现金余额**：从上一期资产负债表"货币资金"期初数
3. **分类现金流**：

   **经营活动现金流** — 与主营业务直接相关的收支：
   - 流入：销售收款、提供劳务收款、收到的税费返还、政府补贴（稳岗补贴等）
   - 流出：采购付款、工资发放、税费缴纳、房租水电、差旅、办公费等

   **投资活动现金流** — 与长期资产购建和对外投资相关的收支：
   - 流入：收回投资本金、收到股息/利息、处置固定资产收款
   - 流出：购买固定资产、在建工程、无形资产、对外投资

   **筹资活动现金流** — 与资本和债务相关的收支：
   - 流入：股东增资、取得银行借款
   - 流出：偿还借款本金、支付利息、向股东分红

4. **现金净增加额 = 经营活动净额 + 投资活动净额 + 筹资活动净额**
5. **期末现金余额 = 期初现金余额 + 现金净增加额**（必须等于资产负债表期末"货币资金"）

## 编制方法

现金流量表不是直接从科目余额取数，而是需要**按收付实现制重新分类**：

- 收入类科目（如应收账款回收）→ 经营活动现金流入
- 费用类科目 → 经营活动现金流出（但要区分哪些是本期实际支付的）
- 固定资产、无形资产购置 → 投资活动现金流出
- 借款、还款 → 筹资活动现金流入/流出

**关键勾稽关系**：
- 期末现金余额 = 资产负债表"货币资金"科目期末余额 ✓
- 经营活动现金流入 ≈ 营业收入 + 应收账款减少 + 预收账款增加
- 支付的税费 ≈ 应交税费期初 + 本期计提 - 应交税费期末

## 分析输出示例

```
💵 现金流分析摘要
═══════════════════════════════════
经营活动现金净额：    +80,000  ✓ 为正，主业造血能力良好
投资活动现金净额：    -30,000     正常投资扩张
筹资活动现金净额：    +10,000     新增借款
───────────────────────────────────
现金净增加额：        +60,000
期初现金余额：        +40,000
期末现金余额：       +100,000  = 资产负债表货币资金 100,000 ✓
═══════════════════════════════════

📊 现金流健康评估：
• 经营活动净额 > 0 ✓ — 主营业务持续产生正向现金流
• 经营净额 > 净利润？若否，可能存在大量应收账款未回收
• 期末现金/月均支出 ≈ 3.2 个月 — 安全垫充足
```

## 重要提示

- 现金流量表中的"现金"包括库存现金、银行存款、其他货币资金
- 支付宝/微信商户余额属于其他货币资金，计入现金
- 定期存款（≥3个月）不属于现金等价物，属于投资活动
- 小企业现金流量表的格式相对简化，不需要像上市公司那样列示间接法
