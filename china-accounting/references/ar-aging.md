
# 应收账龄与催收管理

## 概述
这是一个**日常管理型**技能：把应收账款按拖欠时间分档，找出谁在拖欠、拖欠多久、该催谁，并给出坏账计提参考。与 `audit/receivables.md`（审计视角：函证、截止测试）互补——那个回答"账实是否相符"，这个回答"钱什么时候能收回来"。

## 账龄分档

以**约定付款日（到期日）**为起点计算逾期天数，不是以开票日：

| 账龄档 | 定义 | 风险等级 |
|--------|------|---------|
| 未到期 | 尚在信用期内 | 正常 |
| 逾期 1-30 天 | 轻微逾期 | 关注（多为流程性拖延） |
| 逾期 31-60 天 | 一般逾期 | 催收（电话+书面） |
| 逾期 61-90 天 | 严重逾期 | 强催收（停货评估） |
| 逾期 91-180 天 | 高危 | 专人跟进 / 对账函固定证据 |
| 逾期 181-365 天 | 极高危 | 评估法务手段 |
| 逾期 1 年以上 | 呆账 | 法务 / 核销评估 |

## 分析流程

1. **取数**：应收账款明细账（按客户），含发票号、金额、到期日、已收金额
2. **计算逾期天数**：`逾期天数 = 今天 − 到期日`（部分回款按先到先冲或指定冲抵，与公司政策一致）
3. **分档汇总**：输出账龄分析表（模板见下）
4. **计算 DSO**：`DSO = 应收账款平均余额 / 营业收入 × 期间天数`，与合同平均账期对比，差距大说明回款失控
5. **标记重点客户**：逾期金额 TOP10 + 逾期率（逾期金额/该客户应收总额）异常的客户
6. **坏账计提参考**（企业会计准则，备抵法）

## 坏账计提参考（账龄分析法）

企业会计准则下计提比例由企业自定会计政策，**一经确定不得随意变更**。常见惯例参考：

| 账龄 | 参考计提比例 |
|------|------------|
| 未到期 | 0%-1% |
| 逾期 1 年以内 | 5% |
| 逾期 1-2 年 | 10%-20% |
| 逾期 2-3 年 | 30%-50% |
| 逾期 3 年以上 | 80%-100% |

- 有明确减值证据的**单项计提**优先：对方破产、失联、重大诉讼、经营恶化——不受账龄比例限制，按预计可收回额单独测试
- 小企业会计准则**不计提减值**：坏账实际发生时直接转销，计入营业外支出
- 计提分录（企业准则）：借「信用减值损失」贷「坏账准备」；核销时借「坏账准备」贷「应收账款」，核销后收回冲回

## 催收升级路径

| 阶段 | 触发条件 | 动作 |
|------|---------|------|
| 提醒 | 到期前 3-5 天 | 微信/邮件友好提醒（附对账单） |
| 电话催收 | 逾期 1-30 天 | 确认付款流程卡在谁那里，约定具体付款日 |
| 书面催款 | 逾期 31-60 天 | 发催款函（邮件+纸质，要求签收） |
| 对账函 | 逾期 61 天以上 | 固定债权证据，让对方盖章确认欠款金额 |
| 商务施压 | 逾期 90 天以上 | 停止供货 / 取消账期改现款 / 收取逾期利息（看合同约定） |
| 法务 | 逾期 180 天以上且金额重大 | 律师函 → 支付令 → 诉讼 |

**诉讼时效 3 年**（《民法典》第 188 条，自约定付款日起算）。每次书面催收、对方还款或承诺还款都会**中断时效重新起算**——所以催收记录必须留痕（函件、签收、微信记录），别让债权过了时效。

## 催款函模板

```
催款函

{客户公司名称}：

贵司与我司于 {年月日} 签订的《{合同名称}》（合同编号：{编号}），
合同约定付款日期为 {年月日}。截至本函出具日，贵司尚欠我司
货款人民币 {金额大写}（¥{小写}），已逾期 {N} 天。

请贵司于 {年月日} 前支付上述款项。逾期未付的，我司将按合同
约定收取逾期付款利息，并保留采取进一步措施的权利。

如对上述金额有异议，请于 5 个工作日内书面回复并对账。

联系人：{姓名}  电话：{电话}
{公司名称}（盖章）
{年月日}
```

## 重要提示

- 账龄起点是**到期日**不是开票日——账期 60 天的合同，开票后 30 天不算逾期
- 逾期 1-30 天大多是对方付款流程问题，先电话沟通别急着发函，伤客情
- 对账函和催款函是**证据**，不只是催收手段——对方盖章确认的欠款金额在诉讼中几乎无法抵赖
- 长期挂账且对方失联的，先查工商状态（注销/吊销）再决定核销路径
- 核销坏账不等于放弃债权：账销案存，收回时仍要入账
