
# 合并报表与抵消分录

## 概述
企业会计准则下母公司有子公司的，必须编制合并财务报表（《企业会计准则第 33 号——合并财务报表》）。合并不是简单相加：母子公司之间的投资、交易、往来全部是"内部动作"，对外报表必须抵消。小企业会计准则无合并报表要求。

## 第一步：确定合并范围

以**控制**为基础，三要素同时满足：

1. **权力**：对被投资方拥有主导权（持股 >50% 是典型，但不是唯一——董事会多数席位、一致行动协议、潜在表决权都算）
2. **可变回报**：承担被投资方的可变经营回报
3. **能力**：能用权力影响回报金额

| 情形 | 是否合并 |
|------|---------|
| 直接/间接持股 >50% | ✅ 合并 |
| 持股 50% 但章程约定控制董事会 | ✅ 合并（看实质） |
| 持股 40% 但其余股权高度分散、实际主导经营 | ✅ 合并（看实质） |
| 持股 50% 且另一方有实质否决权（合营） | ❌ 权益法核算 |
| 持股 <20% 无重大影响 | ❌ 金融资产核算 |
| 已宣告清理整顿的子公司 / 破产子公司 | ❌ 不合并 |

## 第二步：统一口径

合并前必须做到：
- **统一会计政策**：子公司政策与母公司不一致的，按母公司口径调整
- **统一会计期间**：子公司资产负债表日与母公司不一致的，调整或要求补编
- 个别报表层面母公司对子公司长投用**成本法**核算，合并工作底稿中先**模拟权益法调整**再抵消

## 第三步：四类抵消分录

### ① 长投与子公司所有者权益抵消（每次合并必做）

```
借：实收资本（子公司期末）
    资本公积（子公司期末）
    盈余公积（子公司期末）
    未分配利润——年末（子公司期末）
    商誉（合并成本 > 可辨认净资产公允价值份额的差额）
    贷：长期股权投资（母公司账面，经权益法调整后）
        少数股东权益（子公司净资产 × 少数股东比例）
```

- 商誉 = 合并成本 − 子公司可辨认净资产公允价值 × 母公司持股比例，只在合并底稿体现，个别报表不出现
- 负商誉（廉价购买利得）计入当期损益（营业外收入），不确认负商誉科目

### ② 内部债权债务抵消

```
借：应付账款（子公司对母公司的应付款）
    贷：应收账款（母公司对子公司的应收款）
```

- 同时抵消内部应收计提的坏账准备：借「应收账款——坏账准备」贷「信用减值损失」
- 内部应收股利/应付股利、内部债券投资/应付债券同理对抵

### ③ 内部交易抵消（存货）

```
母公司卖货给子公司（顺流），成本 80 万售价 100 万，子公司尚未对外出售：
借：营业收入            1,000,000
    贷：营业成本              800,000
        存货（未实现利润）      200,000
```

- 子公司已对外出售的部分不抵消（利润已实现）
- 少数股东不承担顺流交易未实现利润（母公司卖给子公司）；**逆流交易**（子公司卖给母公司）的未实现利润按持股比例分摊给少数股东损益
- 交易产生的内部应收账款同时按 ② 抵消

### ④ 内部交易抵消（固定资产）

母公司卖设备给子公司（原账面 60 万，售价 100 万，子公司按 100 万入固定资产）：

```
借：营业收入            1,000,000
    贷：营业成本              600,000
        固定资产——原价        400,000
```

- 后续每年抵消多提折旧：`借：固定资产——累计折旧 贷：管理费用/销售费用`（多提额 = 400 万虚增 ÷ 剩余年限）
- 逆流交易同理，方向调整

### ⑤ 投资收益与利润分配抵消

```
借：投资收益（母公司享有的子公司净利润份额）
    少数股东损益（少数股东份额）
    未分配利润——年初（子公司）
    贷：提取盈余公积（子公司本年）
        对所有者（或股东）的分配（子公司本年分红）
        未分配利润——年末（子公司）
```

## 合并工作底稿流程

```
1. 母公司、子公司个别报表过入底稿
2. 模拟权益法调整母公司长投（补记子公司净利份额 − 分红）
3. 逐笔编制抵消分录（上述 ①-⑤）
4. 同一项目个别报表数 ± 调整抵消数 = 合并数
5. 验证：合并净利润 = 母公司净利 + 子公司净利 − 内部未实现利润 ± 调整
```

## 输出格式

```
📊 合并抵消分录清单（2026 年度）
════════════════════════════════════════════════════
合并范围：母公司 100% 控股 A 公司、持股 70% 控股 B 公司
────────────────────────────────────────────────────
序号  抵消事项                    借方        贷方
1    长投与A公司权益抵消          8,000,000   8,000,000
     （含商誉 500,000，少数股东权益 0）
2    长投与B公司权益抵消          5,600,000   5,600,000
     （少数股东权益 2,400,000）
3    内部往来抵消（母↔A）          1,200,000   1,200,000
4    内部存货未实现利润（母→A）      200,000     200,000
5    内部固定资产未实现利润（A→母）   150,000     150,000

════════════════════════════════════════════════════

      − 105,000（逆流未实现利润母公司份额）= 4,395,000 ✓
```

## 重要提示

- 抵消分录只做在**合并工作底稿**，母子公司个别账簿永远不动
- 内部交易必须**逐笔对清**：母公司账上 100 万卖给子公司，子公司账上只记 90 万，差的 10 万先查差异再抵消——对不上就说明有漏记或错账
- 子公司净利润要按**购买日可辨认净资产公允价值**持续计算调整（评估增值的折旧摊销差异），不是直接拿子公司报表数
- 少数股东损益 = 子公司调整后净利润 × 少数股东比例，在利润表单独列示
- 同一控制下企业合并（集团内重组）是另一套逻辑：按账面价值合并、差额调资本公积，不确认商誉——别和非同一控制搞混
- 交叉持股、多层间接控股、分步取得控制权的合并对价分步处理较复杂，建议由持证会计师复核
