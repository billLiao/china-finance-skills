
# 财务分析报告

## 概述
这是一个**报告产出型**技能：把三大报表变成管理层能看懂的月度/年度财务分析报告。与 `margins.md` 的区别——那个深挖盈利能力一个点，这个输出完整报告框架。财务岗的价值不在记账，在于让老板看懂数字背后的经营信号。

## 报告框架（六段式）

```
1. 经营概览      一页说清：收入/利润/现金，同比环比，一句话结论
2. 盈利能力      毛利率、净利率、费用率（细节拆解见 margins.md）
3. 营运能力      周转效率：应收、存货、应付、总资产
4. 偿债能力      流动比率、速动比率、资产负债率、利息保障
5. 现金流        经营/投资/筹资净额，利润与现金的背离
6. 风险与建议    本期发现的问题 + 下期行动建议（最重要的一节）
```

## 核心指标体系

### 营运能力（周转类）

| 指标 | 公式 | 判断 |
|------|------|------|
| 应收周转天数 DSO | 平均应收 / 收入 × 期间天数 | 越短越好，对比合同账期 |
| 存货周转天数 DIO | 平均存货 / 营业成本 × 期间天数 | 越短越好，对比行业 |
| 应付周转天数 DPO | 平均应付 / 营业成本 × 期间天数 | 在不伤信用的前提下越长越好 |
| 现金循环周期 CCC | DSO + DIO − DPO | 负数 = 供应商替你垫资（强势商业模式） |

### 偿债能力

| 指标 | 公式 | 参考区间 |
|------|------|---------|
| 流动比率 | 流动资产 / 流动负债 | 1.5-2 较健康，<1 需警惕 |
| 速动比率 | (流动资产 − 存货) / 流动负债 | ≥1 较健康 |
| 资产负债率 | 总负债 / 总资产 | 制造业 40%-60%，贸易类可到 70%，>80% 高危 |
| 利息保障倍数 | EBIT / 利息费用 | >3 安全，<1 利息都赚不回来 |

### 利润与现金的背离（报告必查项）

```
净现比 = 经营活动现金流量净额 / 净利润
```

- 长期 ≥1：利润是真金白银
- 长期 <0.5：利润挂在应收和存货上——收入有水分或回款失控，报告里必须点破
- 净利润为正但经营现金流连续为负：危险信号，结合 `cash-forecast.md` 做资金压力测试

## 分析流程

1. **取数**：本期 + 上期 + 去年同期三套报表（只有两期就做同比）
2. **算指标**：按上面三张表计算，变动超 ±20% 或超参考区间的标记
3. **找异常**：变动大的科目逐个归因（量、价、结构、一次性）
4. **写结论**：每个异常一句话说清"是什么、为什么、怎么办"
5. **给建议**：不超过 5 条，按影响金额排序，每条可执行

## 月度报告 vs 年度报告

| 维度 | 月度报告 | 年度报告 |
|------|---------|---------|
| 篇幅 | 2-3 页 | 10 页以上 |
| 重点 | 异常与行动 | 全年趋势 + 预算达成 + 下年计划 |
| 特有内容 | 环比分析 | 预算 vs 实际、两年趋势图、分红能力评估 |
| 数据颗粒 | 重点科目 | 全科目 + 附注口径说明 |

## 重要提示

- 给管理层的报告**先说结论再摆数据**：老板要的是"有没有事、要不要管"，不是指标罗列
- 所有同比环比注明**口径**：合并口径还是母公司口径、是否含一次性收入，口径不一致的对比是误导
- 单月波动别过度解读：至少看 3 个月趋势再下结论，季节性行业必须对照去年同期
- 报告里的每个数字都要能追溯到报表，管理层追问时答不上来比没有报告更伤信任
- 坏消息（净现比低、逾期增加）必须写——报喜不报忧的财务分析报告没有存在价值
