
# 记账凭证编制

## 概述
按照《会计基础工作规范》(财政部) 和《小企业会计准则》要求，编制标准格式的记账凭证。自动检查借贷平衡，确保凭证符合归档和审计追溯要求。

## 记账凭证必备要素

每张凭证必须包含以下 8 项要素：

| 要素 | 说明 |
|------|------|
| ① 填制日期 | 经济业务发生日期 |
| ② 凭证编号 | 按月连续编号（现收/银收/现付/银付/转 分类或统一编号） |
| ③ 经济业务摘要 | 简明扼要，谁+做了什么+金额——例如"销售A商品给XX公司" |
| ④ 会计科目 | 总账科目 + 明细科目（参照 references/chart-of-accounts.md 科目表） |
| ⑤ 金额 | 借/贷金额，借贷合计必须相等 |
| ⑥ 附件张数 | 原始凭证数量（发票、合同、银行回单、出库单等） |
| ⑦ 签章栏 | 制单人签名 |
| ⑧ 记账标记 | 已过账标记 |

## 编制流程

1. **接收业务信息**：获取业务日期、业务内容、涉及的科目和金额
2. **验证科目**：从 references/chart-of-accounts.md 确认科目编码和名称正确
3. **确认借贷方向**：
   - 资产、成本、费用增加 → 借方
   - 负债、所有者权益、收入增加 → 贷方
   - 反向业务 → 相反方向
4. **写出分录**：每笔分录一行，一个借方对应一个贷方（可一借多贷或多借一贷）
5. **自动验证借贷平衡**：借方合计 = 贷方合计（差异不得>0.01元）
6. **输出标准格式凭证**
7. **标注附件**：列出应附的原始凭证类型

## 标准凭证格式

输出时应使用以下格式：

```
                    记 账 凭 证
                    2026年 5月10日                   转字第001号

┌────────────┬────────────────┬────────────┬────────────┬────────────┐
│   摘  要   │   总账科目     │  明细科目  │  借方金额  │  贷方金额  │
├────────────┼────────────────┼────────────┼────────────┼────────────┤
│ 销售A商品  │ 银行存款       │ 工商银行   │  10,100.00 │            │
│ 给XX公司   │ 主营业务收入   │ A商品收入  │            │  10,000.00 │
│            │ 应交税费       │ 应交增值税 │            │     100.00 │
├────────────┴────────────────┴────────────┼────────────┼────────────┤
│              合  计                      │  10,100.00 │  10,100.00 │
└──────────────────────────────────────────┴────────────┴────────────┘

借贷平衡验证：✓ 借方 10,100.00 = 贷方 10,100.00

附件：增值税普通发票1张、银行回单1张、出库单1张 共3张

会计主管：______  记账：______  审核：______  制单：______
```

## 核心分录模板

### 销售商品（小规模纳税人，税率 1%）

```
借：银行存款（或应收账款）
  贷：主营业务收入           （不含税金额）
      应交税费 — 应交增值税   （不含税金额 × 1%）
```

### 采购商品（小规模纳税人，税款计入成本）

```
借：库存商品（或原材料）     （含税金额）
  贷：银行存款（或应付账款）
```

### 采购商品（一般纳税人，价税分离）

```
借：库存商品                  （不含税金额）
    应交税费 — 应交增值税（进项税额）
  贷：银行存款                 （含税金额）
```

### 支付员工工资

```
借：应付职工薪酬              （应发金额）
  贷：银行存款                 （实发金额）
      应交税费 — 应交个人所得税
      其他应付款 — 社保（个人部分）
      其他应付款 — 公积金（个人部分）
```

### 计提本月折旧

```
借：管理费用 — 折旧费（或制造费用 — 折旧费）
  贷：累计折旧
```

### 计提企业所得税（小企业，应付税款法）

```
借：所得税费用
  贷：应交税费 — 应交企业所得税
```

### 月末结转收入

```
借：主营业务收入
    其他业务收入
    营业外收入
  贷：本年利润
```

### 月末结转成本费用

```
借：本年利润
  贷：主营业务成本
      其他业务成本
      营业税金及附加
      销售费用
      管理费用
      财务费用
      营业外支出
      所得税费用
```

## 验证规则

- [ ] 借贷金额合计相等（差异 = 0）
- [ ] 所有科目编码在科目表中存在
- [ ] 每笔分录有明确的摘要
- [ ] 附件张数已标注
- [ ] 不能将不同类型的经济业务合并为一张凭证
- [ ] 更正错误时使用红字冲销法或补充登记法，不得涂改

## 重要提示

- 凭证编号应按月连续，不能跳号或重号
- 小规模纳税人的采购增值税**全部计入采购成本**，不得抵扣
- 一般纳税人收到增值税专用发票后，必须在发票认证平台勾选确认
- 电子发票（数电票）可作为原始凭证直接入账，需保存XML格式文件
