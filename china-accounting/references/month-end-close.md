
# 月末结账流程

## 使用前必读

根据企业实际情况选择对应版本：

> **快速判断**：一般纳税人 / 年收入≥500万 / 有融资需求 / 多子公司 / 计划上市 → **企业准则版**（完整七步结账，含减值测试+递延税+公允价值调整）。不涉及以上任一情形的小微企业 → **小企业版**（核心五步，跳过企业额外步骤）。不确定时默认选企业准则版。准则判断决策树见本技能 SKILL.md「准则选择」一节。

- 小企业准则 → 执行核心五步 + 跳过标记(企业额外)
- 企业准则 → 执行全部七步

---

## 结账流程总览

```
第一步：计提 — 应提的费用全部提了
第二步：摊销 — 已付的钱摊到这个月
第三步：减值测试 — ⚡企业准则新增：坏账/存货/固定资产/商誉
第四步：公允价值调整 — ⚡企业准则新增：交易性金融资产等
第五步：递延所得税 — ⚡企业准则新增：暂时性差异确认
第六步：结转 — 成本归集 + 损益→本年利润
第七步：对账结账 — 核对→锁账
```

---

## 第一步：计提（两版通用）

### 1.1 计提本月工资
```
借：管理费用/销售费用/制造费用 — 工资
  贷：应付职工薪酬 — 工资
```

### 1.2 计提社保公积金（单位部分）
```
借：管理费用/销售费用/制造费用 — 社保/公积金
  贷：应付职工薪酬 — 社保/公积金
```

### 1.3 计提水电/房租/物业费（已使用未付款）
```
借：管理费用/制造费用
  贷：应付账款/其他应付款
```

### 1.4 计提借款利息
```
借：财务费用 — 利息支出
  贷：应付利息
```

### 1.5 计提增值税附加税
```
借：税金及附加
  贷：应交税费 — 应交城市维护建设税
      应交税费 — 应交教育费附加
      应交税费 — 应交地方教育附加
```

---

## 第二步：摊销（两版通用）

### 2.1 计提本月折旧
```
借：管理费用/制造费用/销售费用 — 折旧费
  贷：累计折旧
```

### 2.2 计提无形资产摊销
```
借：管理费用 — 无形资产摊销
  贷：累计摊销
```

### 2.3 摊销长期待摊费用
```
借：管理费用/销售费用
  贷：长期待摊费用
```

---

## 第三步：减值测试（⚡企业准则新增）

小企业**跳过此步**（不执行减值测试）。

### 3.1 应收账款 — 预期信用损失测试

```
评估应收账款的可收回情况：
- 按账龄分组估算预期损失率
- 对单项金额重大的客户单独测试
- 与上期对比，调整坏账准备余额

借：信用减值损失           （差额，可能是借方也可能是贷方）
  贷：坏账准备
```

### 3.2 存货 — 可变现净值测试

```
检查存货是否贬值：
- 市价持续下跌
- 产品更新换代导致过时
- 毁损、全部或部分陈旧

需要计提：
借：资产减值损失
  贷：存货跌价准备
```

### 3.3 其他资产减值迹象检查

- [ ] 固定资产：停产、闲置、技术淘汰？→如果减值，通过"资产减值损失"
- [ ] 在建工程：项目停建？市场变化？
- [ ] 无形资产：技术落后？法律保护到期？
- [ ] 商誉：每年至少测试一次，无论有无减值迹象

> ⚠ 长期资产减值损失**一经确认不得转回**（存货跌价可以转回）。

---

## 第四步：公允价值调整（⚡企业准则新增）

小企业**跳过此步**。

### 4.1 交易性金融资产按市价调整

```
如果持有的股票/基金/理财产品市价变动：
涨了 → 借：交易性金融资产 / 贷：公允价值变动损益
跌了 → 借：公允价值变动损益 / 贷：交易性金融资产
```

### 4.2 投资性房地产（公允价值模式）

如果选择公允价值模式计量投资性房地产，每期末按市场价调整。

---

## 第五步：递延所得税（⚡企业准则新增）

小企业**跳过此步**。

### 5.1 计算当期暂时性差异

根据第三步减值测试结果和折旧税法差异，重新计算：

```
📋 递延所得税月末确认表

一、递延所得税资产计算
可抵扣暂时性差异项目          金额        税率     应确认递延所得税资产
────────────────────────────────────────────────────────────────
坏账准备                    50,000       25%             12,500
存货跌价准备                20,000       25%              5,000
可抵扣亏损(如有)                 0       25%                  0
────────────────────────────────────────────────────────────────
应确认递延所得税资产合计                              17,500
减：期初已确认递延所得税资产                          12,000
本期增加/(减少)                                        5,500

二、递延所得税负债计算
应纳税暂时性差异项目          金额        税率     应确认递延所得税负债
────────────────────────────────────────────────────────────────
税法折旧快于会计折旧         100,000      25%             25,000
────────────────────────────────────────────────────────────────
本期增加/(减少)                                       25,000

分录：
借：递延所得税资产             5,500
    所得税费用                19,500  (25,000 - 5,500)
  贷：递延所得税负债             25,000
```

## 第六步：结转（两版通用，企业准则条目更多）

### 6.1 结转制造费用→生产成本
```
借：生产成本
  贷：制造费用
```

### 6.2 结转完工产品→库存商品
```
借：库存商品
  贷：生产成本
```

### 6.3 结转发出商品成本→主营业务成本
```
借：主营业务成本
  贷：库存商品
```

### 6.4 结转增值税（一般纳税人）
```
借：应交税费 — 应交增值税（转出未交增值税）
  贷：应交税费 — 未交增值税
```

### 6.5 损益类科目→本年利润

**企业准则完整版分录**（比小企业多了很多科目）：

```
借：主营业务收入
    其他业务收入
    投资收益
    其他收益
    公允价值变动损益（盈利）
    资产处置损益（盈利）
    营业外收入
  贷：本年利润

借：本年利润
  贷：主营业务成本
      其他业务成本
      税金及附加
      销售费用
      管理费用
      研发费用           ← 企业准则新增
      财务费用
      信用减值损失       ← 企业准则新增
      资产减值损失       ← 企业准则新增
      公允价值变动损益（亏损）
      资产处置损益（亏损）
      营业外支出
      所得税费用         ← 含递延所得税后
```

## 第七步：对账与结账（两版通用，企业准则检查项更多）

### 7.1 银行对账
- [ ] 获取所有银行账户对账单
- [ ] 编制余额调节表
- [ ] 差异项逐一排查

### 7.2 支付宝/微信对账
- [ ] 导出商户账单 → 与账面核对

### 7.3 往来款对账
- [ ] 应收账款：大额/长账龄客户重点对
- [ ] 应付账款：大额供应商重点对
- [ ] 其他应收/应付：逐项确认

### 7.4 存货盘点（企业准则严格要求）
- [ ] 企业准则：**必须定期盘点**，监盘或抽盘
- [ ] 盘盈/盘亏处理

### 7.5 税账核对
- [ ] 增值税账面 = 税控系统 = 应申报
- [ ] 各项附加税正确计提
- [ ] 递延所得税余额与差异计算一致 ← 企业准则新增

### 7.6 企业内部核对（企业准则新增）
- [ ] 总账与明细账合计一致
- [ ] 生产成本与库存商品勾稽
- [ ] 收入成本是否匹配（无收入对应的成本、无成本对应的收入）

### 7.7 结账

- [ ] 所有凭证已审核
- [ ] 损益类科目余额全部为零
- [ ] **资产总计 = 负债合计 + 所有者权益合计** ✓（含少数股东权益）
- [ ] 递延所得税确认完毕 ← 企业准则
- [ ] 减值准备余额已更新 ← 企业准则
- [ ] 公允价值调整已完成 ← 企业准则
- [ ] 所有未达账项已解释
- [ ] **结账日期记录：2026年__月__日 已结账**
- [ ] 备份本月账套

## 常见问题及处理

| 问题 | 企业准则处理 |
|------|------------|
| 忘了计提坏账准备 | 补提，如果已跨月：借：信用减值损失 / 贷：坏账准备 |
| 递延所得税忘了调整 | 补调整分录（不影响当期税款，但影响报表） |
| 公允价值变动漏记 | 补记并调整所得税费用（因为会影响利润） |
| 固定资产折旧方法变了 | 属于会计估计变更，使用未来适用法（不追溯） |
| 发现以前年度错误 | **不能直接改当期**！通过"以前年度损益调整"追溯 |
