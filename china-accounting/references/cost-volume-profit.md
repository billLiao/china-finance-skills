
# 本量利与盈亏平衡分析

## 概述
这是一个**决策测算型**技能：算清卖多少保本、卖多少达标、降价能不能换量。接单报价、定销售目标、评估降价促销，都先过一遍本量利（CVP）再拍板。

## 第一步：拆成本性态

| 类型 | 定义 | 典型科目 |
|------|------|---------|
| 变动成本 | 随销量正比变动 | 直接材料、计件工资、销售佣金、运费、包装 |
| 固定成本 | 不随销量变动 | 房租、折旧、管理人员工资、社保基数部分、贷款利息 |
| 混合成本 | 两部分都有 | 水电（基础+用量）、设备维保、客服工资 |

混合成本拆分——**高低点法**：

```
单位变动成本 = (最高业务量成本 − 最低业务量成本) / (最高业务量 − 最低业务量)
固定成本 = 最高点总成本 − 单位变动成本 × 最高点业务量
```

> 拆不准就先按经验比例估（如水电 30% 固定 + 70% 变动），标注"估算"并随数据积累修正。

## 核心公式

```
边际贡献 = 销售收入 − 变动成本
单位边际贡献 = 单价 − 单位变动成本
边际贡献率 = 边际贡献 / 销售收入

盈亏平衡点销售额 = 固定成本 / 边际贡献率
盈亏平衡点销量   = 固定成本 / 单位边际贡献

目标利润销量 = (固定成本 + 目标利润) / 单位边际贡献
安全边际率 = (预计销量 − 保本销量) / 预计销量
```

### 安全边际率判读

| 安全边际率 | 经营状态 |
|-----------|---------|
| >40% | 很安全 |
| 30%-40% | 安全 |
| 20%-30% | 较安全 |
| 10%-20% | 要关注 |
| <10% | 危险——销量跌 10% 就亏损 |

## 多产品情形

多产品用**加权平均边际贡献率**：

```
加权边际贡献率 = Σ(各产品边际贡献率 × 各产品收入占比)
综合保本销售额 = 固定成本 / 加权边际贡献率
```

注意：产品结构变化会改变加权边际贡献率——高毛利产品占比下降，同样的销售额保本点会上移（与 `margins.md` 的结构恶化信号互相印证）。

## 决策应用

### ① 降价促销测算

降价 10% 换量，销量要涨多少才不亏？

```
所需销量增幅 = 原边际贡献率 / (原边际贡献率 − 降价幅度) − 1
例：边际贡献率 40%，降价 10%：
   40% / (40% − 10%) − 1 = 33.3%
→ 销量至少涨 33% 才不亏，先评估渠道能不能承接
```

### ② 特殊订单报价底线

闲置产能接低价单：**变动成本是底线**（固定成本已由正常订单覆盖）。单价 > 单位变动成本即可接，但要评估对正常渠道价格体系的冲击。

### ③ 目标利润倒推

老板定"明年净利 200 万"：目标利润销量 = (固定成本 + 200 万/0.75税后还原) / 单位边际贡献，再对照产能和市场规模判断是否现实。

## 重要提示

- 固定成本是**期间总额**，别除以销量当单位成本用——产能利用率变化时单位"固定成本"是假象
- 折旧、无形摊销是非付现固定成本：算**现金保本点**时可剔除（保本销量更低），但算会计利润保本点必须含
- 存货吸收固定成本会扭曲利润（产量>销量时利润虚高），CVP 测算按**销量**口径，别用产量
- 降价前先算"所需销量增幅"，多数人低估这个数字——40% 边际贡献率降价 10% 要涨 33% 销量才打平
- 测算结果标注数据期间和假设，销量、单价、成本任一假设变了要重算
