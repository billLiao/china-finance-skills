# 中国审计准则 · 审计程序

按照中国注册会计师审计准则 (CAS)，管理从承接业务到出具审计报告的完整流程。针对中小企业审计的特点，自动调整审计策略（如跳过控制测试，重点执行实质性程序）。

## 审计六大阶段

```
1. 初步业务活动 ──→ 2. 风险评估 ──→ 3. 控制测试(可选)
                                      ↓
6. 审计报告 ←── 5. 完成审计 ←── 4. 实质性程序
```

## 适用准则

| 阶段 | 主要准则 |
|------|---------|
| 初步业务活动 | CAS 1111（业务约定书）、CAS 1121（项目质量控制）、CAS 1153（前后任沟通） |
| 风险评估 | **CAS 1211**（识别和评估重大错报风险）、**CAS 1141**（舞弊） |
| 重要性 | **CAS 1221**（重要性） |
| 实质性程序 | **CAS 1231**（应对风险）、**CAS 1312**（函证）、**CAS 1313**（分析程序） |
| 完成 | CAS 1251（评价错报）、CAS 1332（期后事项）、CAS 1341（书面声明） |
| 报告 | **CAS 1501**（审计报告）、**CAS 1502**（非无保留意见）、**CAS 1503**（强调事项段） |

> 完整准则原文参考：中注协官网 https://www.cicpa.org.cn 或 https://docs.maoyanqing.com/auditing/csa/

## 启动审计项目

收到审计请求时，先读取被审计单位的记忆文件（见「记忆机制」一节），记忆中已有的信息直接沿用，再问清缺失项：

```

3. 企业规模：
   □ 小型（年收入<500万，员工<20人）
   □ 中型（年收入500万-2亿，员工<300人）
   □ 大型

   □ 年度审计  □ 专项审计  □ 内部审计  □ 其他

   □ 科目余额表（期初/期末）  □ 明细账  □ 记账凭证
   □ 银行对账单  □ 纳税申报表（增值税/企业所得税/个税）

   □ 存货清单  □ 员工名册 + 工资表
════════════════════════════════════
```

## 审计策略选择

| 策略 | 适用对象 | 特点 |
|------|---------|------|
| **简化审计** | 微型企业（年收入<100万） | 重点科目全覆盖实质性程序，少量抽样 |
| **标准审计** | 中小企业 | 所有科目实质性程序 + 重要性判断 |
| **详细审计** | 中大型/高风险 | 控制测试 + 实质性程序 + 全面函证 |

## 记忆机制（被审计单位档案）

审计是年度重复工作，上年的发现直接决定本年的重点。本技能通过本地记忆积累被审计单位知识，年复一年越用越懂这家公司。

### 记忆位置

与 accounting 技能共用记忆根目录：默认 `~/.china-finance-skills/companies/{被审计单位名}/`，可用环境变量 `CHINA_FINANCE_MEMORY_PATH` 自定义。审计发现包含客户敏感信息，**只存本地，绝不写入任何 git 仓库或上传**。

### 工作流

1. **项目启动**：确认被审计单位 → 读取 `profile.md`（不存在则先建档，可复用 accounting 技能已建的公司档案）和 `findings.md`
2. **上年发现是本年必查项**：`findings.md` 中状态为「跟进中 / 未更正」的事项，自动列入本年审计重点，并在风险评估时重新评估相关错报风险
3. **连续两年出现同类问题**：提示升级为重点关注，考虑对相关认定扩大样本或追加程序
4. **审计发现经用户确认后**写入 `findings.md` 并告知写入了什么；未确认的推断只在对话中呈现，不入记忆

### findings.md 模板

```markdown
# 审计发现跟踪
| 年度 | 科目 | 问题描述 | 类型 | 状态 | 确认日期 |
|---|---|---|---|---|---|
| 2025 | 应收账款 | 3笔函证未回函，未执行替代程序 | 一般 | 已更正 | 2026-01-15 |
```

类型：重大 / 一般 / 微小；状态：跟进中 / 已更正 / 未更正。

## 重要提示

- 本技能负责**调度和跟踪**，各科目详细审计程序见对应参考文档
- 所有审计证据和工作底稿必须保留，归档期限为审计报告日后**60天内**
- 工作底稿保存期限至少**10年**（CAS 1131）
- 发现问题应及时与客户管理层沟通，重大的需与治理层沟通（CAS 1151）

> 免责声明：本技能提供审计流程指导，实际审计工作应由持有注册会计师（CPA）执业资格的专业人士执行。
