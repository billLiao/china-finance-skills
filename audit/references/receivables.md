
# 应收账款实质性程序

## 概述
应收账款是中小企业审计的重点科目——许多小企业的应收账款管理混乱，账龄不清、坏账不处理。本技能依据 CAS 1312（函证）提供完整的审计程序。

## 审计目标

| 认定 | 目标 |
|------|------|
| 存在 | 应收账款确实存在，不是虚构的 |
| 完整性 | 所有的应收都已入账 |
| 计价 | 坏账准备计提充分（小企业：直接转销法） |
| 权利 | 应收账款归被审计单位所有 |

## 程序二：函证

### 选取标准

- 大额项目
- 账龄长的项目
- 关联方项目
- 有纠纷或异常的项目
- 交易频繁但期末余额小的项目（可能期末已还清但全年交易额大）

### 函证控制要求（同现金审计）

| 环节 | 要求 |
|------|------|
| 发函 | CPA 亲自发出，核实对方地址 |
| 回函 | 直接寄至事务所，不经过被审计单位 |
| 跟函 | 如跟函，CPA需全程保持对函证的控制 |

### 未回函的替代程序

| 替代程序 | 做法 |
|---------|------|
| 检查期后收款 | 查看资产负债表日后的银行收款记录 |
| 检查交易凭证 | 销售合同、发票、发货单、客户签收单 |
| 查询对方信息 | 通过企查查/天眼查核查对方经营状态 |
| 延伸检查 | 必要时实地走访重要客户 |

## 程序三：坏账准备测试

### 小企业会计准则（直接转销法）

小企业**不计提坏账准备**，坏账损失在实际发生时直接计入营业外支出：
```
借：营业外支出
  贷：应收账款
```

审计关注：是否存在应转销而尚未转销的坏账？

### 企业会计准则（备抵法 - 预期信用损失模型）

如果是按企业会计准则的一般企业，则需：
1. 了解坏账计提政策
2. 获取账龄分析表
3. 按计提比例重新计算
4. 比较账面已提与应提的差异

```
📋 坏账准备重新计算表

账龄         余额       计提比例   应提准备     账面已提    差异
──────────────────────────────────────────────────────────
1年以内     250,000      5%       12,500      10,000     +2,500
1-2年        85,000     20%       17,000      15,000     +2,000
2-3年        30,000     50%       15,000      10,000     +5,000
3年以上      15,000    100%       15,000           0    +15,000
──────────────────────────────────────────────────────────
合计        380,000               59,500      35,000    +24,500  ← 少提
══════════════════════════════════════════════════════════
```

## 程序四：截止测试

选取资产负债表日前后各 5-10 笔销售记录：

```
📋 应收账款截止测试
索引号：ZC-5

日期       凭证号   摘要              金额      是否跨期
────────────────────────────────────────────────────────
5月28日   转015   销售给A公司       50,000    ✅ 正确（5月）
5月31日   转018   销售给B公司       30,000    ✅ 正确（5月）
6月1日    转001   销售给C公司       20,000    ⚠ 检查发货日期
────────────────────────────────────────────────────────

发现：
  转001(6月1日) 发货日期为5月30日 → 应计入5月收入
  → 审计调整：借：应收账款 20,000 / 贷：营业收入 20,000
```

## 程序五：重分类检查

| 情况 | 处理 |
|------|------|
| 应收账款**贷方余额** | 重分类至**预收账款** |
| 预收账款**借方余额** | 重分类至**应收账款** |

## 关键分析程序

| 指标 | 计算 | 预警信号 |
|------|------|---------|
| 应收账款周转天数 | 应收/日均收入 | 显著高于同行→回款慢 |
| 坏账率 | 坏账/收入 | 突然升高→客户质量恶化 |
| 收入增速 vs 应收增速 | 比较 | 应收增速>收入增速→可能在虚增收入 |

## 常见问题

| 问题 | 处理 |
|------|------|
| 账龄和客户说的不一致 | 以函证结果为准，差异调查 |
| 大量应收集中在少数客户 | 客户集中度风险，可能需要额外披露 |
| 老板个人账户代收货款 | 内控缺陷，需做审计调整 |
| 关联方应收长期挂账 | 需调查商业实质，可能不是真实应收 |
