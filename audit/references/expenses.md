
# 费用实质性程序

## 概述
费用审计覆盖销售费用、管理费用和财务费用三大类。中小企业费用的常见问题是：公私不分、白条入账、该计提的未计提、不该抵扣进项的抵扣了。审计重点是费用的**发生是否真实**、**分类是否正确**、**归集是否完整**。

## 审计目标

| 认定 | 目标 |
|------|------|
| 发生 | 费用是真实发生的 |
| 完整性 | 所有该记的费用都已入账 |
| 准确性 | 金额正确 |
| 分类 | 费用归类正确（管理费用 vs 销售费用 vs 财务费用） |
| 截止 | 费用记录在正确期间 |

## 程序一：实质性分析程序

### 1.1 月度趋势分析

```
📊 管理费用月度趋势分析
════════════════════════════════════

费目          1月      2月      3月      4月      5月
─────────────────────────────────────────────────────
工资         15,000   15,000   15,000   15,000   15,000  稳定 ✓
房租          8,000    8,000    8,000    8,000    8,000  稳定 ✓
办公费        2,500    3,200    2,100    2,800   12,000  ⚠ 5月异常
差旅费        1,200    3,500    1,800    2,000    2,400  波动正常
咨询费            0        0        0        0   50,000  ⚠ 新增大额

5月办公费 12,000：
  明细：办公家具8,000 + 办公用品4,000
  → 办公家具8,000应作为固定资产管理（非费用！）

5月咨询费 50,000：
  → 检查咨询合同和服务成果，确认商业合理性
```

### 1.2 费用率分析

```
📊 费用率分析
════════════════════════════════════

                    本期        同期       正常范围
──────────────────────────────────────────────────
销售费用/收入       8.2%        6.5%       5%-12%
管理费用/收入       9.8%        7.2%       5%-10%  ⚠ 偏高
财务费用/收入       0.5%        0.3%       0%-2%

管理费用率偏高分析：
  1. 咨询费50,000占收入5% — 拉高了费用率
  2. 办公费中固定资产错计为费用也推高了费用率
  3. 剔除上述一次性因素后，费用率约7.2% — 正常
```

### 1.3 与预算对比

如果有预算，将实际费用与预算对比，查找重大差异。

## 程序二：细节测试（抽凭）

选取大额或异常费用，检查原始凭证：

```
📋 费用抽查测试表
索引号：ZU-3

日期     凭证号   费目       金额     发票    合同    审批单   异常
──────────────────────────────────────────────────────────────
5月10日 转020   差旅费     3,500    ✅      —      —        ⚠ 无审批
5月15日 转025   咨询费    50,000    ✅      ✅      ✅       ⚠ 无服务成果
5月20日 转030   办公费    12,000    ✅      —      —        ⚠ 含固定资产
5月22日 转035   招待费     4,500    ✅      —      ✅       —
──────────────────────────────────────────────────────────────

发现：
  1. 转020: 差旅费无审批单 — 虽金额小，但反映内控薄弱
  2. 转025: 咨询费无服务成果证明 — 需要补充或可能不真实
  3. 转030: 办公费含8,000元家具 — 需重分类至固定资产
```

## 程序四：费用完整性检查

**检查是否有该记没记的费用**：

| 检查内容 | 方法 |
|---------|------|
| 员工工资和社保 | 核对工资表、社保缴纳记录与账面计提 |
| 各项税费 | 核对申报表上的应纳税额与账面计提数 |
| 折旧和摊销 | 重新计算本期折旧和摊销，看是否漏提 |
| 借款利息 | 核对借款合同利率与账面利息计提 |
| 长期待摊费用 | 检查是否按受益期摊销 |

## 程序五：主要费用科目关注点

### 5.1 工资薪金

- 工资表上的人是否真实在职？
- 工资是否与行业水平相符？（异常高的个人工资可能是利益输送）
- 社保公积金是否按规定缴纳？

### 5.2 业务招待费

> ⚠ 税务限额：不超过营业收入0.5%的部分可在企业所得税前扣除（超出部分需纳税调增）。

- 招待费是否真实？有无虚假报销？
- 是否存在以"咨询费""会议费"名义变相列支的招待费？

### 5.3 差旅费

- 出差是否有审批？有无出差报告？
- 交通票据是否与出差时间地点一致？
- 有无个人旅游混入差旅费报销？

### 5.4 咨询费/服务费

中小企业最常见的"灵活费用"科目——也是最容易被用来做利益输送的科目：

- 咨询服务是否有合同？有实质成果？
- 收款方是否与公司有特殊关系？
- 金额是否与市场价匹配？

### 5.5 租赁费

> 如果适用新租赁准则（企业会计准则，非小企业准则），经营租赁也需要确认使用权资产和租赁负债。

### 5.6 财务费用

| 检查项 | 内容 |
|--------|------|
| 利息支出 | 核对借款合同约定的利率，重新计算应计利息 |
| 利息收入 | 银行存款应有利息收入，是否已入账？ |
| 汇兑损益 | 外币业务是否按期末汇率调整？ |
| 银行手续费 | 抽查银行对账单上的手续费与账面是否一致 |

## 关键分析指标

| 指标 | 计算 | 预警 |
|------|------|------|
| 费用率趋势 | 月度费用/收入 | 突然变化→需解释 |
| 人均费用 | 总费用/人数 | 异常→可能虚报人头或费用 |
| 费用结构变化 | 类别占比 | 如咨询费从0跳升到30%→需查 |
| 费用 vs 支付 | 计提 vs 实付 | 只计提不支付→可能虚假费用 |

## 常见审计调整

| 问题 | 调整 |
|------|------|
| 费用跨期 | 借/贷管理费用：调整到正确期间 |
| 固定资产错计费用 | 借：固定资产 / 贷：管理费用（同时补提折旧） |
| 费用分类错误 | 借：正确科目 / 贷：错误科目 |
| 漏记费用 | 借：费用 / 贷：应付账款/其他应付款 |
